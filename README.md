# QuranHackathon

## Repository Structure

```
├── deenquest/              # Main Next.js application
│   ├── ProjectFeatures.md  # Full feature documentation
│   └── ...                 # Source code
├── prompt.md               # Base feature spec used to build the project
├── questionHackathon.md    # Official hackathon questions & requirements
└── README.md               # This file
```

## Key Files

- **`questionHackathon.md`** — Contains the official hackathon questions and requirements we need to satisfy.
- **`prompt.md`** — The base feature specification the project was built from.
- **`deenquest/ProjectFeatures.md`** — Detailed documentation of every implemented feature, page, API, component, and Firestore collection.

## Quick Start

```bash
cd deenquest
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The `.env.local` is already included — no extra setup needed.
